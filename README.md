## 📌 Описание

Полностью адаптивный лендинг, посвящённый путешествию по Исландии.  
Сайт выполнен **на чистом HTML, CSS и JavaScript**, без использования библиотек и фреймворков.  

▶️ **Демо:** [https://pyatkovo.github.io/iceland.github.io/](https://pyatkovo.github.io/iceland.github.io/)

## 🎯 Основной функционал

- 📱 Полная адаптивность — мобильная и десктоп-версия
- 🎠 **Кастомная карусель** без библиотек
- 🖼️ **Галерея изображений** с интерактивом
- 📬 Форма отправки заявки:
  - валидация полей
  - popup успешной отправки

## 🛠 Используемые технологии

- HTML5
- CSS (включая media queries)
- JavaScript (без библиотек)
- GitHub Pages (деплой)
